# Stellbeauty Massage & Spa

Responsive single-page booking experience for Stellbeauty Massage & Spa (Wuse 2, Abuja).

## Stack
- Vite + React + TypeScript

## Development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Deploy
- Output directory: `dist`
- Cloudflare Pages headers: `public/_headers` (Google Fonts and Unsplash allowlisted)
